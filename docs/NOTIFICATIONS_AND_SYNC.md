# Notifications, affichage et synchronisation

Windows utilise les notifications système AWT, avec icône Kovelyx et retour à l’application au clic. L’application doit rester ouverte ou réduite ; aucune tâche de démarrage cachée n’est installée. Les restrictions de notifications de Windows peuvent empêcher l’affichage. Le planificateur ne livre qu’une fois les sorties du jour à partir de 9 h. Android conserve WorkManager et son canal de notification, vérifie aussi les canaux désactivés et demande l’autorisation sur le thread principal. Le test fonctionne sans série enregistrée. Le bouton Paramètres du système permet de réactiver les alertes.

Le canal et la vérification des mises à jour se trouvent dans Avancé sur les trois plateformes. La recherche suit cet emplacement. Les réglages de fréquence affichent les modes de l’écran, les bornes retenues et le mode réellement signalé ; ils concernent les Hz de l’écran, pas des images vidéo inventées. Le sélecteur ajuste ensemble les bornes si nécessaire, et n’ajoute aucun mode au pilote. Maximum 144 Hz, même résolution, préférence locale à chaque appareil.

Les images statiques importées sont normalisées avant leur enregistrement sur Android. Les fichiers sources peuvent atteindre 64 Mo, dans la limite de 32 mégapixels ; le cloud reçoit l’image optimisée. Les GIF sont identifiés par leur signature et conservés animés, jusqu’à 18 Mo. Windows utilise aussi le décodeur Skia déjà livré pour WebP. Un format inconnu ou non décodable produit une erreur ; tous les formats existants ne peuvent pas être garantis. Les versions téléchargées restent des copies privées par appareil.

La reprise de l’application déclenche une synchronisation Cloudflare immédiate. Les changements locaux gardent leur envoi différé court et leurs reprises après échec ; la réception périodique reste à 60 secondes quand l’application est active. Sur TV, les échecs d’avatar et de fond sont indépendants et font réessayer la synchronisation. Un appareil fermé, hors ligne ou suspendu reçoit les changements à sa prochaine reprise connectée. Il n’existe pas de réception instantanée garantie sur un appareil éteint.

Les catalogues natifs de Ma-Collection/Kaptain sont transmis par blocs, avec manifeste atomique et SHA-256. Les définitions, dossiers, affiches et URL d’animation sont conservés ; les vidéos et octets des affiches ne sont pas recopiés. Le JSON de configuration est limité à 4 Mo par ensemble pour maîtriser la consommation D1. Les modifications du site doivent être réimportées dans Kovelyx : le site Kaptain ne se connecte pas directement au compte Cloudflare Kovelyx. Le test complet utilise 18 collections et 756 dossiers publics et vérifie aussi qu’un catalogue inchangé n’est pas retransféré.
