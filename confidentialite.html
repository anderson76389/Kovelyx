Confidentialité

Cette page présente le fonctionnement du projet open source Kovelyx. Elle ne décrit pas un service d'hébergement de comptes déjà lancé.

Utilisation sans compte

Le mode invité conserve les profils et préférences localement sur l'appareil. Il n'offre pas de synchronisation entre Windows, Android et TV. Les données locales peuvent être perdues lors de la suppression des données de l'application.

Connexions optionnelles

Lorsque tu ajoutes un serveur ou connectes Trakt, MDBList, TMDB, une extension ou un service de lecture, l'application communique avec ces fournisseurs pour les fonctions demandées. Leurs politiques de confidentialité s'appliquent aux données qu'ils traitent. Des identifiants d'intégration et jetons peuvent être conservés sur l'appareil afin de maintenir la connexion.

Données techniques

Selon la configuration, le logiciel peut utiliser des outils de diagnostic et interroger GitHub pour rechercher les mises à jour. Ce site ne stocke pas de vidéos.

Compte Kovelyx

Au 14 octobre 2026, aucun serveur de comptes Kovelyx par défaut n'est en service. Un futur déploiement devra publier ses propres modalités de stockage, d'effacement, d'hébergement et de sécurité des comptes.

Contact et code source

Pour signaler une question ou un dysfonctionnement, utilise les issues GitHub Kovelyx. N'y publie jamais de mots de passe, clés API ni jetons privés.
